SALMA'S ROYAL BIRTHDAY INVITATION — FLAT ZIP

FILES (all directly in this ZIP; no folders)
- index.html: website with the supplied Salma portrait on the cover and interactive event-details page.
- index-previous.html: preserved previous version.
- salma-hero.png: supplied portrait used on the cover.
- birthday-song.mp3: background birthday music.
- README.txt: these instructions.

GITHUB PAGES
1. Extract this ZIP.
2. Upload all five files to the ROOT of your GitHub repository (do not put them inside a folder).
3. Open repository Settings → Pages.
4. Select Deploy from a branch, choose main and /(root), then Save.
5. Wait for the published URL shown in Settings → Pages.

MUSIC
The song starts after the visitor presses Open the Invitation (browser autoplay restrictions). The same audio element stays active when switching between the cover and details, so the song does not restart.
